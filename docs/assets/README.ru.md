# Медиа для README

[English](README.md) · [Русский](README.ru.md)

GIF и скриншоты списка сняты на playground библиотеки версии 0.2.0; текст стендов и тестовых
данных переведён во временной сборке. Скриншот разных фонов получен из текущего англоязычного
playground с loadshape 0.2.2. В состояниях загрузки и контента используются одинаковые данные.

| Файл                 | Стенд               | Содержимое                                               |
| -------------------- | ------------------- | -------------------------------------------------------- |
| skeleton.gif         | /stands/list        | Список, загрузка и контент, ширина 960 px, 12 кадров/с   |
| skeleton-card.gif    | /stands/card        | Карточка, загрузка и контент, 392 × 414 px, 12 кадров/с  |
| skeleton-page.gif    | /stands/page        | Страница, загрузка и контент, ширина 960 px, 12 кадров/с |
| skeleton-loading.png | /stands/list        | Список при загрузке, 1120 × 704 px                       |
| skeleton-content.png | /stands/list        | Готовый список, 1120 × 704 px                            |
| surfaces.png         | /stands/backgrounds | Заглушки на разных фонах, 1120 × 704 px                  |

Список использует Skeleton.Repeat. На странице навигация находится вне Root, а заголовок ленты
сохранён с помощью Skeleton.Static. Оформление задаёт playground.

## Запись

Собери playground и запусти его без инструментов разработки:

```sh
pnpm --filter playground build
pnpm --filter playground exec vite preview --host 127.0.0.1 --port 4185
```

Исходные GIF записаны с playground, использующего `loadshape@0.2.0`, в Chromium с тёмной темой и обычной анимацией;
текст был переведён во временной сборке. В текущем playground текст уже английский, а элементы
управления дополнены. Размеры окна: 1120 × 704 для списка, 800 × 620 для карточки и 1120 × 1000
для страницы. Записывай с частотой 15 кадров/с, выдерживая каждое состояние минимум две секунды.
Скриншот фонов в текущей версии снят в светлой теме при 1120 × 704.
Для страницы и карточки обрежь пустые поля; координаты и команда ffmpeg приведены в
[английской версии](README.md#capture). Готовые GIF сохранены с частотой 12 кадров/с.

README пакета использует абсолютные ссылки на GitHub, чтобы изображения отображались в npm.
Корневой README использует относительные пути. Медиа находятся здесь и не входят в npm-архив.
