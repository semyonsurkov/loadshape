# Язык предметной области

## Термины

- **Заглушка (скелетон)** — состояние блока, пока данные не пришли: на месте содержимого плашки
  той же геометрии, что и итоговый контент.
- **Корень (`Skeleton.Root`)** — элемент внутри контейнера проекта, который переводит своё
  поддерево в режим заглушки атрибутом `data-skeleton="loading"`. Контейнер проекта он не
  заменяет.
- **Лист** — элемент поддерева, который в режиме заглушки становится плашкой: текст, медиа,
  кнопка, поле ввода, а также пустой элемент с атрибутом `data-skeleton-bone`. Иконки `svg`,
  рамки, фоны и отступы контейнеров листьями не считаются и остаются настоящими.
- **Статичное (`Skeleton.Static`, атрибут `data-skeleton-static`)** — часть поддерева, известная
  без запроса: подписи, иконки, названия из конфига. Рисуется настоящей и в режиме заглушки.
  Без `render` оборачивается в `span` с `display: contents`; внутри таблицы, списка и `select`
  получает `render` с элементом этого уровня (`render={<thead />}`). Данные в одной строке со
  статичным оборачиваются в свой элемент, иначе голый текст рядом останется без полосы.
- **Подставные данные (placeholder)** — значения того же типа, что и настоящие данные, с типичной
  длиной строк и числом элементов. Компонент рендерит их, пока идёт загрузка, поэтому заглушка
  получает настоящую вёрстку. Подставляются через `placeholderData` TanStack Query, а корень
  берёт флаг `isPlaceholderData`; без Query через `data ?? PLACEHOLDER`. Своего хука у
  библиотеки нет.
- **Задержка появления** — около 150 мс, в течение которых заглушка или спиннер невидимы, чтобы
  быстрая загрузка не мигала. Общая для всех компонентов переменная `--loadshape_delay`.
- **Спиннер (`Spinner`)** — кольцо на месте, где структуры нет: в иконке-кнопке, в строке
  статуса, в пустой области. Размер `1em`, цвет `currentColor`, декоративный без `label`.
- **Полоса перехода (`RouteProgress`)** — индикатор загрузки следующей страницы при переходе
  между маршрутами. Общий компонент получает pending; адаптер `loadshape/tanstack-router`
  читает status роутера и сбрасывает задержку при смене href. Полоса декоративна и показывает
  факт работы без процентов. При reduced-motion она остаётся неподвижной.

## Инварианты

- Библиотека не задаёт внешний вид: цвета, радиусы и длительности приходят из CSS-переменных,
  которые проект связывает со своими токенами.
- Геометрия заглушки совпадает с геометрией контента, потому что это одна и та же вёрстка; ни
  один размер заглушки не задаётся руками.
- Заглушка декоративна: корень в режиме заглушки получает `inert` и недоступен для фокуса и
  скринридера, а `aria-busy` ставит проект на свой контейнер вокруг корня (ADR 0005).
- Заглушка выглядит частью страницы, куда встроена: фон, рамки и тени контейнеров остаются
  настоящими, а цвет плашки по умолчанию выводится из цвета текста в этом месте
  (полупрозрачная примесь `currentColor`). Поэтому плашка одинаково читается на светлой
  странице, на тёмной секции и на цветном баннере без отдельной настройки. Текст прячется через
  `-webkit-text-fill-color`, а не через `color`, иначе `currentColor` станет прозрачным.
- При `prefers-reduced-motion: reduce` мерцание выключено, задержка появления остаётся.
- Поля ввода и кнопки внутри заглушки имеют оформление проекта, а медиа размер или
  `aspect-ratio`: без этого WebKit меняет размер неоформленного поля, а пустая картинка схлопывается.
- Основной импорт в рантайме зависит только от React. Адаптер TanStack Router имеет отдельную
  точку входа и optional peer, который не нужен потребителю Skeleton, Spinner и общего RouteProgress.
