# 0002. Стек библиотеки: pnpm workspace, tsdown, React 19, GitHub и npm

- Статус: accepted
- Дата: 2026-10-09
- Решали: Semyon Surkov вместе с агентом при заведении проекта

## Контекст и проблема

`loadshape` это публичная библиотека с playground для стендов и скиллом для агента. Нужно выбрать
менеджер пакетов, сборщик, минимальную версию React, способ поставки полосы перехода и место
основного репозитория. Все остальные проекты пользователя сидят на npm и хостятся в GitLab с
зеркалами.

## Рассмотренные варианты

- **npm workspaces, как в остальных проектах** — за: единообразие / против: у библиотек экосистемы
  стандарт pnpm (на нём Base UI, Radix Primitives, TanStack, React Router, Next.js, Vite, shadcn/ui
  и Zustand, проверено по полю `packageManager`), и контрибьютор ждёт его.
- **pnpm workspaces** — за: стандарт для React-библиотек, строгий `node_modules` ловит
  незаявленные импорты / против: отличается от остальных проектов пользователя.
- **Turborepo поверх workspace** — за: дефолт `architecture-infra.md` / против: на двух пакетах
  кешировать нечего.
- **tsup** — за: популярен / против: в README сам объявлен неподдерживаемым и отправляет на tsdown.
- **tsdown** — за: преемник tsup на Rolldown / против: версия 0.x.
- **React 18 и 19** — за: шире охват / против: для `inert` нужен обходной путь, как в Radix.
- **Только React 19** — за: нативный `inert`, текущая основная версия / против: проекты на 18 не
  подключат.
- **`RouteProgress` только под TanStack Router** — за: меньше кода / против: не подключить к другому
  роутеру.
- **Общий `RouteProgress pending` и адаптер `loadshape/tanstack-router`** — за: работает с любым
  роутером, TanStack из коробки / против: лишняя точка входа.
- **GitLab основным с зеркалами** — за: как остальные репозитории / против: `npx skills add`
  ставит скилл из GitHub, issues публичной библиотеки ищут там же.

## Решение

Выбрали pnpm workspaces без Turborepo (`packages/loadshape`, `apps/playground`), сборку tsdown,
только React 19 как peer, общий `RouteProgress` с адаптером под TanStack Router, GitHub основным
репозиторием, публикацию на npm под MIT с версиями через changesets, потому что это стандарт
экосистемы React-библиотек и он даёт установку скилла одной командой.

## Последствия

Перед стартом локальный pnpm 11.9.0 обновляется до закреплённой версии. Проекты на React 18
библиотеку не подключат, пока не обновятся. Turborepo добавляется, если пакетов станет больше
двух-трёх. Зеркала в GitLab и GitVerse заводятся по желанию пользователя.
