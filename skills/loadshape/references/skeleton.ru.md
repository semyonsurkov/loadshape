# Подключение Skeleton

[English](skeleton.md) · [Русский](skeleton.ru.md)

Подробные примеры и контракт Root, Static и Repeat находятся в [README пакета](https://github.com/semyonsurkov/loadshape/blob/main/packages/loadshape/README.ru.md#skeleton).
Подключи CSS один раз. Передавай loading в Skeleton.Root и `aria-busy` в окружающий контейнер:
Root становится inert и исчезает из дерева доступности. Через `render` используй допустимый
элемент для таблицы или списка; пользовательский компонент должен передавать атрибуты и ref в DOM.

Skeleton.Static сохраняет всё своё поддерево. Размещай внутри только известное до запроса;
динамическое значение рядом со статичной подписью оборачивай в отдельный элемент. Намеренно
пустую плашку помечай `data-skeleton-bone`.

С TanStack Query передавай placeholderData и используй isPlaceholderData как признак загрузки:
при подставных данных isPending уже false. Сохраняй ошибки, пустые ответы, disabled и кеш при
фоновом обновлении. Без Query используй данные или подставные значения и признак загрузки того
же запроса. Заглушки должны соответствовать типам, форматтерам, датам, enum и обычной длине текста.

Резервируй размеры изображений и оформляй поля средствами приложения: неоформленные элементы
в WebKit могут изменить размер при закраске. SVG остаётся видимым; графику целиком из SVG может
понадобиться отдельное состояние загрузки. Кнопка отмены остаётся вне inert Root. CSS-переменные
и reduced-motion описаны в [API](https://github.com/semyonsurkov/loadshape/blob/main/packages/loadshape/README.ru.md#css-переменные).
