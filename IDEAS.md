# Идеи

- React Native: точка входа `loadshape/native` с тем же API
- Pending кнопки: `data-pending` прячет подпись без смены ширины, спиннер по центру, `aria-busy`
- Кеш подписей после первой загрузки, чтобы повторный визит рисовал заголовки и вкладки настоящими
- Зеркала репозитория в GitLab и GitVerse
